# Response Surface
A critical step in kinetic model optimization and uncertainty minimization is to develop a surrogate model (or response surface) that maps a predicted combustion property (e.g., ignition delay) to reaction model parameters within their ranges of uncertainties. The resposne surfaces make large-scale optimization feasible by accelerating the evaluation of the objective function using algebraic relationships, instead of directly solving differential equations for each combustion target.
