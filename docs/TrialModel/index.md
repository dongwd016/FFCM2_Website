# Trial Model
{: .no_toc }
The trial model is compiled by evaluating the state of knowledge for reaction pathways, rate constant expressions, rate parameter uncertainties, and the thermochemical and transport data for reaction kinetics of C<sub>0-4</sub> species. The trial FFCM-2 model consists of 96 species and 1054 reactions, and references kinetic studies from 227 papers that date back to 1960.
